该模块为纯配置型仓库元数据，包含三类内容：
- `workflows/release.yml`：单一 CI/CD 流水线，基于 `on.push.tags[v*]` 和 `workflow_dispatch` 触发，在 `macos-26` 运行器上执行 Xcode 26.6、校验 VERSION/BUILD_NUMBER/RELEASE_NOTES.md/CHANGELOG.md 一致性、缓存语音识别运行时、运行 `swift test`、通过 `script/package_dmg.sh` 生成 DMG 并校验 SHA256，最后用 `gh release create/edit` 上传产物。
- `PULL_REQUEST_TEMPLATE.md`：统一 PR 描述结构（Summary/Verification/Screenshots/Checklist），约束变更范围与安全检查。
- `ISSUE_TEMPLATE/`：目录存在但当前为空，预留 issue 模板位置。
依赖方向单向：工作流仅依赖仓库根目录下的 `VERSION`、`BUILD_NUMBER`、`RELEASE_NOTES.md`、`CHANGELOG.md`、`script/bootstrap_runtime.sh`、`script/package_dmg.sh` 及 Swift 源码，不反向依赖其他模块。
