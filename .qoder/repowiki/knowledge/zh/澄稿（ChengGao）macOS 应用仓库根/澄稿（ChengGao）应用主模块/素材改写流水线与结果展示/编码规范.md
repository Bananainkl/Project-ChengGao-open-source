- 所有异步任务通过 `Task { ... }` 启动并在入口处调用 `Task.checkCancellation()` 支持取消，错误统一捕获后写入 `errorMessage` 与 `statusMessage`。
- 对外暴露的可变状态属性在 `didSet` 中同步持久化到 `UserDefaults`，键名采用带前缀的字符串（如 `onlineAI.provider`、`outputLanguage`）。
- 网络请求体通过静态方法集中构建（如 `requestBody`、`prompt`、`retryPrompt`），system instruction 与 prompt 模板以 `nonisolated static` 常量或方法形式维护，便于测试与替换。
- 错误类型统一遵循 `LocalizedError` 协议并提供中文 `errorDescription`，通过 `throw` 抛出并由上层统一转换为本地化消息显示。
- UI 组件通过 `@Bindable var store: RewriteStore` 绑定 store 状态，所有用户交互最终转化为对 store 方法的调用，视图本身不持有业务逻辑。
