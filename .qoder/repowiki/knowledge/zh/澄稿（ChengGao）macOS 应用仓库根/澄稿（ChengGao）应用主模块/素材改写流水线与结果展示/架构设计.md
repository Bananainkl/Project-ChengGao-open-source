模块以 `RewriteProcessing` 协议为统一抽象，由两个 actor 实现：`OfflineRewritePipeline`（纯本地文本清洗、分句、按风格拼接的确定性流水线）和 `OpenRouterRewritePipeline`（通过 `OpenRouterAPIClient` 调用 HTTP JSON 接口，含重试、结构化输出解析、质量检查与事实修复）。`RewriteStore` 作为 `@Observable` 的 MainActor 单例状态中心，持有 pipeline、visualPromptGenerator、imageGenerator、extractor 等依赖，通过 `startRewrite()` 编排素材提取 → 改写 → 视觉提示词生成 → 封面/分镜图片生成的完整流程，并将进度通过 `RewriteProgress` 回调推回 UI。UI 层由三个 SwiftUI View 组成：`ComposerView` 负责素材输入与参数选择并触发 `store.startRewrite()`；`ResultView` 作为结果页容器，委托 `OutputView` 渲染五分页（原稿校对、修改建议、成稿、镜头配图、视频建议），所有图片生成操作均通过 store 的方法异步执行并持久化到历史目录。依赖方向单向：Views → Store → Pipeline/Generators，Store 通过构造注入可替换的 pipeline 与 image generator 实现解耦。
