- 每个功能以 `enum` 暴露静态方法作为 API 入口（如 `DouyinVideoResolver.resolve`、`CoverArtworkPlanner.artworks`、`ShortVideoExportPackage.export`），内部实现细节封装在私有方法中。
- 异步网络/JS 操作统一标注 `@MainActor`，并通过 `withCheckedThrowingContinuation` 包装 `webView.evaluateJavaScript` 转为 async throws。
- JSON 解析采用 `JSONSerialization.jsonObject` 配合 `firstString(in:keys:)`、`collectHTTPURLs` 等通用辅助函数，对字段名做多别名兼容（如 `aweme_id`/`itemId`、`play_addr`/`download_addr`）。
- 字符串清理统一使用 `flatten(_:)` 辅助函数，通过正则替换连续空白并 trim，保证提示词与文件名的一致性。
- 错误通过自定义 `LocalizedError` 枚举（如 `ShortVideoExportPackageError`、`SourceExtractionError`）表达，并在抛出前检查前置条件（目录存在性、文件类型等）。
- 对外部不可靠输入（网页 payload、用户标题）一律先做安全过滤：非法字符剔除、长度截断、去重（`Set<String>`）后再使用。
