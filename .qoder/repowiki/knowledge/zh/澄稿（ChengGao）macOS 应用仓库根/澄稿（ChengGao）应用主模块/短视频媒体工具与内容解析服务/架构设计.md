本模块由一组职责单一的枚举/结构体组成，围绕 `RewriteOutput` 这一核心输出类型协作：
- 提示词与分镜：`VisualPromptGenerator.swift` 通过 `AdaptiveVisualPromptGenerator` actor 调用在线 AI（OpenRouter / WebAIChatClient），按批次生成 `VisualShot`；`CoverArtworkGenerator.swift` 的 `CoverArtworkPlanner` 基于 `CoverFormat`（竖版 3:4、横版 16:9）生成封面提示词，`CoverArtworkRenderer` 使用 AppKit 的 `NSImage`/`NSGraphicsContext` 合成标题渐变与阴影。
- 批量文档：`ChatGPTImageBatchDocument.swift` 将分镜与封面任务组织成带批次协议的 Markdown 文档，供 ChatGPT 分批执行生图。
- 平台解析：`DouyinVideoResolver.swift` 与 `XiaohongshuContentResolver.swift` 均通过 `PlatformWebSessionPool.shared.session(for:)` 获取 `WKWebView`，注入 JS 脚本抓取 JSON 数据并解析为 `ResolvedDouyinVideo` / `ResolvedXiaohongshuContent`；小红书解析器还包含 `OnlineSourceVisualAnalyzer` actor，优先用 OpenRouter 视觉模型识别图片，失败时回退到本地 Vision 框架。
- 媒体处理：`VideoFrameTextExtractor.swift` 使用 `AVAssetImageGenerator` + Vision 文本识别从视频中抽取字幕式可见文字。
- 导出：`ShortVideoExportPackage.swift` 将已生成的图片、封面、改写文稿与分镜提示词打包为目录结构，原子写入后返回统计结果。
依赖方向单向向外：本模块消费上层 `RewriteOutput`、`ResearchContent`、`PlatformWebSessionPool`、`OpenRouterAPIClient`、`WebAIChatClient` 等，不反向依赖 UI 层。
