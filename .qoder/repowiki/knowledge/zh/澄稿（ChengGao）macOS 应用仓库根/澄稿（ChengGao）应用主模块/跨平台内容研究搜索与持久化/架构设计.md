模块按 Services / Stores / Views 三层划分：
- Services 层：`ResearchDatabase`（actor）封装 CSQLite 直接操作，维护 accounts、tasks、contents、task_contents 四张表及外键/唯一索引；`ResearchSearchService`（actor）实现 `ResearchSearching` 协议，通过 `withThrowingTaskGroup` 并发两路调用各平台，Bilibili 优先走 API 再回退 HTML，YouTube 优先 Data API Key 再回退浏览器；`WebKitResearchSearchService` 通过 WKWebView + JS 注入抓取渲染后数据，支持抖音/小红书响应体捕获。
- Stores 层：`ResearchStore` 是 @MainActor @Observable 的单一状态源，协调 searchService、database 生命周期，管理搜索结果、任务历史、账号会话与 YouTube API Key 持久化。
- Views 层：`ResearchView` 提供关键词输入、平台选择、结果列表与详情面板；`ResearchAccountsView` 管理各平台账号登录与 YouTube Key 配置。
依赖方向单向向下：Views → Store → Services → SQLite/WebKit/URLSession。
