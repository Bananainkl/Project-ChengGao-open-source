本模块按职责分为两层：
- `Models/` 目录集中存放纯数据模型与枚举，包括 `ModelProfile`、`MemoryBudget`（本地模型配置）、`OnlineAIConfiguration` / `OnlineImageGenerationConfiguration`（在线 API 配置）、`ResearchPlatform` / `ResearchContent`（多平台研究数据）、`RewriteOutput` / `VisualShot` / `CoverArtwork`（改写产物与视觉提示词），以及 `WebAIProvider` / `WebAIConfiguration`（Web 端 AI 集成）。所有类型均遵循 `Identifiable`、`Codable`、`Sendable` 协议，便于 SwiftUI 展示与并发传递。
- `Services/` 目录实现具体能力，通过 protocol 抽象边界：`SpeechTranscribing`（由 `LocalSpeechTranscriber` 基于 whisper.cpp 实现）、`TerminologyVerifying`（由 `WikipediaTerminologyVerifier` 实现）、`SourceExtracting` / `ResearchSourceExtracting`（由 `SourceExtractor` 统一处理 Bilibili、YouTube、抖音、小红书与网页正文）、`ImageGenerating`（由 `CompatibleImageGenerationClient` 适配 OpenAI 兼容图片接口）。
- 无外部依赖的纯计算逻辑以 `enum` + static 方法形式提供，如 `SpokenSubtitleFormatter`、`VideoSuggestionPlanner`、`VisualShotPlanner`、`VisualPromptDesigner`、`ImagePromptBuilder`。
- 凭证与持久化通过独立 store 类封装：`OpenRouterCredentialStore` / `ResearchCredentialStore` 使用 POSIX 0600 权限文件存储密钥，`PlatformSessionStore` 基于 WKWebView 管理各平台 Cookie 登录态。
- 依赖方向单向：Services 消费 Models，Models 不反向依赖 Services；Service 之间通过 protocol 解耦，避免循环引用。
