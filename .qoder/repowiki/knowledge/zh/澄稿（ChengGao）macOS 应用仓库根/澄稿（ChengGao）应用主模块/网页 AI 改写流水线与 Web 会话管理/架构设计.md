本模块围绕「网页浏览器自动化」构建三层结构：
- 编排层 `WebAIRewritePipeline`（实现 `RewriteProcessing`）负责组装提示词、调用 `WebAIChatClient` 发起改写、执行质量门检查并在失败时自动重试。
- 客户端层 `WebAIChatClient` 作为 Sendable 桥接配置提供者与底层会话池，将结果包装为 `OpenRouterCompletion` 供上层统一消费。
- 会话层 `WebAIWebSession` 封装单个 `WKWebView` 的生命周期（后台渲染窗口、编辑器就绪检测、认证状态判断）、通过注入 JavaScript 脚本完成输入框填充与发送按钮点击，并使用 begin/end 标记轮询响应；`WebAIWebSessionPool` 以单例按 `WebAIProvider` 缓存会话。
- 辅助能力 `OnlineAIModelCatalogClient` 基于 `URLSession` 拉取 OpenAI 兼容的 `/v1/models` 列表，解析多种返回格式。
- UI 层 `WebAILoginView` + `WebAILoginSheet` + `WebAIWebView(NSViewRepresentable)` 提供登录流程，Coordinator 定时轮询 `isEditorReady` / `isAuthenticated` 并驱动状态绑定。
依赖方向单向：Views → Services → WebKit；所有 WKWebView 操作均标注 `@MainActor`，JS 脚本通过 `evaluateJavaScript` 异步回调封装为 Swift async/await。
