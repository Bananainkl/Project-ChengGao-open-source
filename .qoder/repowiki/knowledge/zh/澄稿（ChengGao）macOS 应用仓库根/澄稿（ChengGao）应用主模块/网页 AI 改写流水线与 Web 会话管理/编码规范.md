- 所有涉及 WKWebView 的类与方法均标注 `@MainActor`，并通过 `javascriptBool` / `javascriptString` 将 JS 回调封装为 async/await。
- 错误类型统一采用 `enum ...: LocalizedError, Equatable` 形式，并在 `errorDescription` 中拼接 provider 名称以便用户定位。
- JS 脚本通过 `jsonLiteral` 安全转义后嵌入字符串模板，避免直接拼接原始字符串造成注入风险。
- 会话池采用单例 + 字典缓存模式，提供 `session(for:)`、`webView(for:)`、`discard(_:)` 三件套，并按 Provider/Platform 维度隔离。
- 提示词构造使用 `nonisolated static func` 生成固定模板，再在调用处注入 material/style/language 等动态参数。
