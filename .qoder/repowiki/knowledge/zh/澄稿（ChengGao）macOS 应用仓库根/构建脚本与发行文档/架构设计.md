本模块由两类内容组成：
- `script/` 下的 Bash 脚本构成一条单向依赖链：`bootstrap_runtime.sh` 负责下载并校验 whisper.cpp xcframework、模型与许可证到 `Frameworks/Models/Licenses`；`build_and_run.sh` 基于 `swift build -c release` 生成二进制，组装 `.app`（Info.plist、Resources、Frameworks、Codesign ad-hoc），并提供 run/debug/logs/telemetry/verify/package 等子模式；`package_dmg.sh` 调用前两者生成 DMG 并输出 SHA-256；`release_local.sh` 串联测试+打包+安装用于本地验证；`package_release.sh` 是对外发布的唯一入口，执行全量测试、Developer ID 签名、Hardened Runtime、notarytool 公证与 stapler 装订。
- `docs/` 存放面向用户的安装说明（随 DMG 分发）以及面向维护者的 RELEASE_ACCEPTANCE.md、RELEASE_NOTARIZATION.md、CURRENT_HANDOFF.md 等验收与交接文档。
依赖方向严格自下而上：bootstrap → build → package → release，版本号与构建号统一从根目录 `VERSION` 与 `BUILD_NUMBER` 读取，所有外部资源均通过固定 URL + SHA-256 校验保证可重复性。
